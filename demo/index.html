paperjs-offset

Offset and expanded stroke examples for Paper.js paths

These examples run against the browser bundle in this repository. Rebuild with npm run build after changing the library code.

Closed path offset

Positive offsets expand the source path; negative offsets contract it. The source stays visible on top.

Join styles

Use miter, bevel, or round joins when connecting adjacent offset curves.

Compound shape cleanup

Boolean-normalized shapes can be offset repeatedly, but aggressive negative offsets may still expose edge cases.

Stroke expansion

offsetStroke expands open paths into filled outlines, with butt and round caps for terminals.
